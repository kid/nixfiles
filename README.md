# ❄️ nixfiles

### 📖 About

Declarative system configurations for my Linux ([NixOS](https://nixos.org/)) and macOS machines (using [nix-darwin](https://github.com/nix-darwin/nix-darwin)).

It is based on [flake-parts](https://flake.parts/) and [easy-hosts](https://github.com/tgirlcloud/easy-hosts)

### 🔧 Other dependencies:

- [home-manager](https://github.com/nix-community/home-manager) of course for managing user configurations
- [stylix](https://github.com/danth/stylix) for provides consistent ricing for the entier system
- [plasma-manager](https://github.com/nix-community/plasma-manager) for managing my KDE configuration
- [sops-nix](https://github.com/Mic92/sops-nix) for storing secrets and exposing them to hosts
- [treefmt-nix](https://github.com/numtide/treefmt-nix) one formatter to rule them all
